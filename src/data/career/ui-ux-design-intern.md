#### Job Description

Explore user interface and user experience design by creating wireframes, design components, and interactive prototypes. Gain hands-on exposure to design systems, user journeys, accessibility, and visual hierarchy principles.

#### Responsibilities

- Create wireframes, low-fidelity sketches, and digital mockups for web and mobile interfaces.
- Develop interactive prototypes in Figma demonstrating clear user flows.
- Apply typography, color palettes, and spacing rules according to modern design tokens.
- Participate in design critiques, gather feedback, and iterate on design solutions.
- Organize design assets and export production-ready specifications.

#### What You Will Bring

- Curiosity, creative enthusiasm, and an interest in user experience design.
- Willingness to experiment with modern design tools such as Figma.
- Openness to constructive critiques and eagerness to refine design work.
- Good communication and visual presentation skills.

#### Skills You Can Develop

- End-to-end interface design using modern industry tools like Figma.
- Design system fundamentals, design tokens, and component reuse.
- Usability heuristics, user flow analysis, and wireframe creation.
- Interactive prototyping and visual storytelling.
- Creation of polished case studies and portfolio pieces.

#### Benefits of the Program

- Practical learning experience through structured assignments.
- Skill development through real-world scenarios and hands-on exercises.
- Feedback and progress evaluation where available.
- Portfolio-worthy work samples to demonstrate your capabilities.
- Internship completion certificate upon meeting the program's completion requirements.

> **Important Disclosure:** This internship is strictly unpaid, carries no stipend or guaranteed employment, and does not require any application or certificate fee.
