#### Job Description

Learn the fundamentals of modern website development and responsive user interfaces in a structured, practical setting. You will practice building clean web pages, testing across devices, identifying bugs, and understanding modern frontend development workflows.

#### Responsibilities

- Build and modify responsive webpage layouts using semantic HTML and CSS.
- Practice DOM manipulation and interactive logic with JavaScript.
- Test web layouts across different screen sizes and browsers for visual consistency.
- Learn and use Git for version control and collaborative assignments.
- Document code changes and participate in structured review sessions.

#### What You Will Bring

- Curiosity, willingness to learn, and genuine interest in web technologies.
- Basic understanding of HTML and CSS concepts (beginners with zero formal experience are welcome).
- Reliability, good communication, and dedication to personal skill development.
- Openness to feedback and iteration on coding exercises.

#### Skills You Can Develop

- Modern semantic HTML5, CSS layout techniques (Flexbox, Grid), and responsive design.
- Practical JavaScript fundamentals and DOM manipulation.
- Version control workflows with Git and GitHub.
- Web performance optimization and debugging techniques.
- Professional documentation and project hygiene.

#### Benefits of the Program

- Practical learning experience through structured assignments.
- Skill development through real-world scenarios and hands-on exercises.
- Feedback and progress evaluation where available.
- Portfolio-worthy work samples to demonstrate your capabilities.
- Internship completion certificate upon meeting the program's completion requirements.

> **Important Disclosure:** This internship is strictly unpaid, carries no stipend or guaranteed employment, and does not require any application or certificate fee.
