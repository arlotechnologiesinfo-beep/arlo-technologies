#### Job Description

Develop foundational coding, application testing, and problem-solving skills in a structured learning environment. Work on programming assignments, explore application logic, perform code testing and debugging, and understand software design patterns.

#### Responsibilities

- Write clean, structured code to implement assigned application features or utility functions.
- Learn to integrate REST APIs and manage client data states cleanly.
- Debug runtime errors and investigate edge cases through methodical troubleshooting.
- Perform manual and unit testing on application components to ensure code stability.
- Participate in peer reviews and apply suggestions to refine code quality.

#### What You Will Bring

- Curiosity, logical reasoning, and a passion for coding and software engineering.
- Basic understanding of fundamental programming principles (variables, control flow, functions).
- Commitment to a full-time internship schedule for focused learning and skill building.
- Reliability, self-discipline, and strong communication skills.

#### Skills You Can Develop

- Modern application architecture in TypeScript and JavaScript.
- Effective debugging, error logging, and diagnostic skills.
- API consumption, asynchronous programming, and state management.
- Code quality standards, testing practices, and Git collaboration workflows.

#### Benefits of the Program

- Practical learning experience through structured assignments.
- Skill development through real-world scenarios and hands-on exercises.
- Feedback and progress evaluation where available.
- Portfolio-worthy work samples to demonstrate your capabilities.
- Internship completion certificate upon meeting the program's completion requirements.

> **Important Disclosure:** This internship is strictly unpaid, carries no stipend or guaranteed employment, and does not require any application or certificate fee.
